# 古文乐园

给孩子的古诗古文引导练习：读一句、点一个字看笔顺，在田字格里试写，再把打乱的字块排回完整诗句。

## 本地运行

这是一个无需构建工具的静态站点。可以直接打开 `index.html`，也可以在仓库目录运行：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 功能

- 内置《静夜思》《春晓》《悯农（其二）》和《论语》一则，可按古诗/古文筛选。
- 点击诗句中的任意汉字，打开 HanziWriter 笔顺演示与田字格描写练习。
- 将每句汉字打乱，孩子点击字块排序；答对后会记录进度并提示下一句。
- 使用浏览器本地存储保存已完成句子，不需要账号或后端。

书写动画依赖 jsDelivr 上的 HanziWriter；网络不可用时仍会显示汉字结构提示，并可继续完成排序练习。
