# 古文乐园

给孩子的古文阅读小书架：欢迎首页 → 选择年级 → 古文列表 → 古文详情。详情页支持大字号原文、标题/作者/朝代逐字学习、古诗逐句讲解、汉字拼音与读音、逐字汉字课堂、知识点卡片、课文小练习、上一篇/下一篇和朗读。

## 本地运行

这是无需构建工具的静态站点。首次运行或新增课文后，先在项目根目录执行内容扫描：

```bash
python scripts/scan_content.py
```

然后启动静态服务器（浏览器需要通过 HTTP 请求 `content/manifest.json`）：

```bash
python -m http.server 4173
```

访问 <http://localhost:4173>。Windows 也可以使用 `py scripts/scan_content.py` 和 `py -m http.server 4173`。

## 新增 TXT 课文

文件必须放在 `content/grade<number>/lesson<number>.txt`，例如 `content/grade3/lesson10.txt`。扫描脚本会按年级号、课文号数字排序，并生成 `content/manifest.json`。

推荐使用以下格式：

```text
标题：
《咏鹅》
作者：
骆宾王
出处：
《全唐诗》
原文：
鹅，鹅，鹅，曲项向天歌。
译文：
白鹅向着天空歌唱。
逐句译文：
白鹅啊白鹅，弯曲着脖子向着天空歌唱。
洁白的羽毛漂浮在碧绿的水面上，红红的脚掌拨动着清清的水波。
朗读音频：
audio/grade1/yong-e.mp3
知识点：
1. 曲项：弯曲的脖子。
2. 拨：划动。
```

也支持 `# title: ...`、`# author: ...`、`## 原文`、`## 译文`、`## 知识点` 等 Markdown 风格区块。字段名支持标题、作者、出处/来源、故事、简介、类型、汉字、原文、译文、逐句译文、朗读音频、知识点、注释、赏析及对应英文名。古诗的 `逐句译文` 按原文行一一对应，详情页会显示在每句下方；作者字段可写成 `[唐] 李白`，其中朝代和作者汉字都可以点击学习。需要整首古诗真人录音时，可在 TXT 添加 `朗读音频：` 相对路径；未配置时系统会先尝试真人语料，找不到整首录音才回退到设备中文语音。脚本兼容 UTF-8 BOM、CRLF/LF、缺少字段和未知区块；缺少字段/未知区块会写入 warnings，单个无法读取的文件会写入 errors，不会阻止其他课文进入清单。manifest 输出版本为 2。

### 课文小练习格式

可在 TXT 的 `小练习：` 后添加故事排序题和选择题。扫描器会始终为课文保留一组“选字排序”练习（如果 TXT 已经写了排序题，也会补上这组字块练习）；没有显式小练习时，则只生成默认字块排序题。过长段落会切短，并限制默认题数量。

```text
小练习：
[排序]
提示：想一想故事发生的顺序。
句子：第一句
句子：第二句
[/排序]
[选择]
题目：主人公做了什么？
选项：A｜答案一
选项：B｜答案二
答案：A
解析：原文中可以找到答案。
[/选择]
```

排序题按 `句子：` 的先后作为正确顺序；每个句子仍会生成带独立 ID 的字符 token，因此重复汉字也能分别点击和撤回。选字排序完成一句后会自动切换下一句。`汉字：` 区块可写成 `庭：tíng｜庭院`，为汉字弹窗提供可选拼音和释义；没有填写时会自动显示拼音。还可以填写第三段录音地址，例如 `光：guāng｜光亮｜audio/guang.mp3`，点击听读音时会优先播放这段本地真人录音；没有配置本地录音时会尝试普通话真人音频，网络或资源不可用才回退到设备朗读。

内容只作为 JSON 文本由前端渲染，TXT 中的 HTML 特殊字符会被安全转义，原文换行会保留。浏览器端不会枚举服务器目录。

## 测试与验收

### 全文默写

课文原文下方的“全文默写 · 屏幕写字”进入独立练习页：先阅读原文，再隐藏全文，孩子用手指在田字格里逐字书写。每个字按笔顺检查，写对后自动进入下一个字；一句完成后再进入下一句。

- 不需要键盘，也不需要切换输入法，适合手机和平板触屏。
- 可以查看淡淡的笔顺轮廓，再显示当前汉字并演示笔顺；提示使用情况会显示在完成页。
- 草稿及进度保存在当前设备浏览器。退出后可以继续，原文内容更新会开始新练习；从头练习会替换该篇上次的默写进度。
- 新增 TXT 自动获得全文默写功能，无需额外填写题目。

默写逻辑测试：`node --test tests/dictation.test.cjs`。部署时还需上传 `dictation.js` 与 `dictation.css`。

```bash
python scripts/scan_content.py
python -m unittest discover -s tests -v
```

验收时应确认：扫描输出包含当前的 17 篇示例课文（其中三年级 14 篇，已移除两个长段节选并加入《舟夜书所见》）；`content/manifest.json` 中年级/课文按数字排序且始终有一年级至六年级 6 个年级；首页主按钮进入第一个有内容的年级；六个年级卡片都可打开，空年级显示空状态；列表可进入详情，刷新详情 URL 仍能恢复；标题、作者与朝代可逐字点击，古诗每句下方显示对应讲解，汉字弹窗显示拼音并可听读音，原文可朗读，选字排序会自动切换下一句，移动端布局可用。

## 静态部署约束

部署时需同时上传 `index.html`、`styles.css`、`app.js`、`content/manifest.json` 以及 `content/` 下的 TXT 文件。新增或修改 TXT 后只需重新运行扫描脚本并重新部署静态文件，不需要修改业务代码，也不需要构建工具或后端目录接口。
